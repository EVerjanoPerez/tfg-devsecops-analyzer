1. **Crear la estructura ordenada:**

Creamos una jerarquía limpia (C:\\Users\\12401\\Desktop\\espe\\2027\\TFG\\Codigo\\backend). Separamos el código de los documentos y recursos para mantener una organización profesional.

2. **Crear un Entorno Virtual (venv):**

Usamos Python para crear una carpeta llamada venv dentro de backend.

¿Qué significa? Es una "burbuja" o caja aislada para tu proyecto. Todo lo que instalemos aquí dentro no afecta al resto del ordenador. Así evitamos que conflictos de versiones rompan tu código en el futuro.

3. **Instalar las herramientas de servidor (FastAPI y Uvicorn):**

Descargamos FastAPI (el framework o "cerebro" que sabe gestionar peticiones web) y Uvicorn (el motor que enciende el servidor físico en tu ordenador).

4. **Crear el archivo main.py:**

Es el archivo de código principal donde escribimos las órdenes que el servidor debe ejecutar.
